# Sistema-Integral-de-Gesti-n-de-Clientes-Servicios-y-Reservas
Proyecto Actividad 4 de Programación (Ing. de Sistemas - UNAD). Aplicación basada en POO para la empresa "Software FJ", diseñada para gestionar clientes, servicios (salas, equipos, asesorías) y reservas.

***
### Justificacion del proyecto
Debido a ciertas diferencias en el enfoque del proyecto, he tomado la decisión de llevar a cabo el desarrollo de esta aplicación de manera individual. Asumo la responsabilidad total de esta situación debido a una falta de comunicación oportuna de mi parte, eximiendo a mi equipo de cualquier falta.

A partir de aquí, y como esto significa que de entrada ya no cumplo con el requisito de trabajar en grupo, voy a plantear y justificar una ruta un poco distinta para hacer las cosas. Básicamente, me tomaré la libertad de aprovechar mis ratos libres para probar, experimentar y armar la aplicación de la forma que considero más adecuada para que funcione bien, manteniendo lo mas importante que es el uso y aplicacion de programacion POO, Abstraccion y Polimorfismo.

También quiero comentar que, al estar yo solo haciendo push, lógicamente ya no se podrá ver el uso de Git en un entorno colaborativo ni esos típicos conflictos entre ramas. Sin embargo, es un tema que no me preocupa porque la dinámica de trabajo en equipo con Git es algo que ya conozco y manejo sin problema desde hace varios meses.
